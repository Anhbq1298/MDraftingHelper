# MDraftingHeper

AutoCAD 2021 (R24.0, x64) add-in for 2D structural drafting. One Ribbon tab, **MDraftingHeper**, with three tools:

| Button | Command | What it does |
| --- | --- | --- |
| Rebar Percentage | `MDH_REBAR` | Counts rebar Circles inside a closed boundary and inserts a native Table with As, Ag and ρ |
| Tie & Hook | `MDH_TIE` | Draws a tie between two bar Circles with 90°/135°/180° hooks as a lightweight polyline with true arcs |
| Steel Section | `MDH_STEEL` | Inserts CHS, SHS, RHS, UB and UC sections as native Dynamic Blocks whose dimensions are edited in Properties (Ctrl+1) |

C# / .NET Framework 4.8 / WPF. Scope is 2D drafting only; no design checks.

## Layout

```text
src/MDraftingHeper.Core         geometry, rebar, hooks, steel, profile import (no Autodesk types)
src/MDraftingHeper.UI           WPF dialogs, view models, preview (no Autodesk types)
src/MDraftingHeper.AutoCAD2021  IExtensionApplication, Ribbon, commands, CAD readers/writers, metadata
src/MDraftingHeper.Data         demo profiles (labelled DEMO), CSV template, hook presets
assets/DynamicBlocks            MDH_SteelSections.dwg — generated by tools/DynamicBlocks
assets/Icons                    16/32 px Ribbon icons (tools/Make-Icons.ps1)
tests/MDraftingHeper.Core.Tests xUnit tests for Core
tools/                          template authoring, bundle build, in-AutoCAD host tests
deploy/                         bundle manifest, per-user install/uninstall scripts
docs/                           build/debug, user guide, block authoring, acceptance report
samples/                        drawing produced by the host self-test
```

## Quick start

```powershell
Copy-Item Acad.user.props.example Acad.user.props   # set Acad2021Dir if AutoCAD is elsewhere
dotnet test tests\MDraftingHeper.Core.Tests\MDraftingHeper.Core.Tests.csproj
.\tools\Build-Bundle.ps1
.\deploy\Install-MDraftingHeper.ps1                # AutoCAD must be closed
```

See [docs/Build-and-Debug.md](docs/Build-and-Debug.md), [docs/User-Guide.md](docs/User-Guide.md) and the verification status in [docs/Acceptance-Checks.md](docs/Acceptance-Checks.md).

## AutoCAD MCP server (Claude Code ⇄ AutoCAD 2021)

`mcp/` holds a Python MCP server (stdio, project-scoped in `.mcp.json` as `autocad`). It lets Claude Code inspect a running AutoCAD 2021 and make focused, validated edits in test drawings. It builds on [acad-cmd](https://github.com/EmptyKot/acad-cmd), cloned unmodified into `external/` by the installer.

```powershell
.\mcp\install.ps1                    # venv, pinned deps, diagnostic
.\mcp\tests\Start-TestAutoCAD.ps1    # AutoCAD 2021 + test drawing
claude                               # approve the 'autocad' project server once
```

Docs: [setup](docs/mcp/setup.md), [architecture](docs/mcp/architecture.md), [troubleshooting](docs/mcp/troubleshooting.md), [upstream notes](docs/mcp/upstream-notes.md), [test report](docs/mcp/test-report.md). Agent guidance: [CLAUDE.md](CLAUDE.md).

## Important limitations

- The shipped steel profiles are **demonstration data** only. Dlubal (or other) data must be obtained under its licence and imported as JSON/CSV.
- The "EC2 + Singapore NA" hook preset is **unverified** candidate values. Use the Manual preset until verified rules are entered.
- The rebar table is a snapshot. Ties do not follow moved bars.
